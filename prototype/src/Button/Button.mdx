<Subtitle>Accessible, themeable button — React Aria behavior, styled entirely from Paragon design tokens.</Subtitle>

`Button` is the prototype re-implementation of Paragon's `Button` on the modern
stack proposed in [ADR&nbsp;0022](https://github.com/openedx/paragon). Its public
prop API is unchanged from `@openedx/paragon`, but its internals no longer depend
on Bootstrap or `react-bootstrap`:

- **Behavior** comes from [React Aria](https://react-spectrum.adobe.com/react-aria/)'s
  `useButton` — cross-device press handling, keyboard support, and correct
  `disabled` semantics even when the button is rendered as an `<a>`.
- **Styling** is a co-located CSS Module that reads the same `--pgn-*` design
  tokens the library ships today, so theming (including `@edx/brand` overrides)
  is unaffected.
- **Focus** uses a keyboard-only focus ring (`:focus-visible` via React Aria's
  `[data-focus-visible]`).

## Variants

Eleven base variants, each with `outline-`, `inverse-`, and `inverse-outline-`
forms. Variant theming is a pure remapping of design-token CSS variables — no
per-variant styles are hand-written.

<LiveExample code={`
<div style={{ display: 'flex', gap: '0.75rem', flexWrap: 'wrap' }}>
  <Button variant="primary">primary</Button>
  <Button variant="secondary">secondary</Button>
  <Button variant="brand">brand</Button>
  <Button variant="success">success</Button>
  <Button variant="danger">danger</Button>
  <Button variant="outline-primary">outline-primary</Button>
  <Button variant="inverse-primary">inverse-primary</Button>
  <Button variant="link">link</Button>
</div>
`} />

## Sizes

`sm`, `md` (default), `lg`, and Paragon's `inline` size for buttons that sit
within a line of text.

<LiveExample code={`
<div style={{ display: 'flex', gap: '0.75rem', alignItems: 'center' }}>
  <Button size="sm">Small</Button>
  <Button size="md">Medium</Button>
  <Button size="lg">Large</Button>
</div>
`} />

## Icons

Pass any icon component to \`iconBefore\` and/or \`iconAfter\`.

<LiveExample code={`
<div style={{ display: 'flex', gap: '0.75rem' }}>
  <Button iconBefore={DotIcon}>Icon before</Button>
  <Button iconAfter={DotIcon}>Icon after</Button>
  <Button iconBefore={DotIcon} iconAfter={DotIcon}>Both</Button>
</div>
`} />

## Polymorphism (`as`)

Render as any element while keeping accessible button behavior. A disabled
anchor is handled via `aria-disabled` rather than the legacy
`pointer-events: none` hack.

<LiveExample code={`
<div style={{ display: 'flex', gap: '0.75rem' }}>
  <Button as="a" href="https://openedx.org" variant="primary">Link button</Button>
  <Button as="a" variant="outline-primary" disabled>Disabled anchor</Button>
</div>
`} />

## Grouping

Related buttons can be combined with `ButtonGroup` and `ButtonToolbar` — see the
[ButtonGroup](?path=/docs/buttonlike-buttongroup--docs) page.

## Accessibility notes

- Keyboard: activates on <kbd>Enter</kbd> and <kbd>Space</kbd>; the focus ring
  appears only for keyboard focus.
- `onPress` is preferred for new code; `onClick` is bridged for API
  compatibility with the current Paragon Button.
- When rendering icon-only buttons, provide an `aria-label`.
