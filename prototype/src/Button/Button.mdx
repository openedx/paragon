<Subtitle>Accessible, themeable button — React Aria behavior, styled entirely from Paragon design tokens.</Subtitle>

`Button` is the prototype re-implementation of Paragon's `Button` on the modern
stack proposed in [ADR&nbsp;0022](https://github.com/openedx/paragon). Its public
prop API is unchanged from `@openedx/paragon`, but its internals no longer depend
on Bootstrap or `react-bootstrap`:

- **Behavior** comes from [React Aria](https://react-spectrum.adobe.com/react-aria/)'s
  `useButton` — cross-device press handling, keyboard support, and correct
  `disabled` semantics even when the button is rendered as an `<a>`.
- **Styling** is a co-located CSS Module that reads the same `--pgn-*` design
  tokens the library ships today, so theming (including `@edx/brand` overrides)
  is unaffected.
- **Focus** uses a keyboard-only focus ring (`:focus-visible` via React Aria's
  `[data-focus-visible]`).

## Stateful buttons

To implement a loading state, Paragon provides the `StatefulButton` component
(not part of this prototype). It manages and displays loading/complete states
for a more efficient, user-friendly experience.

## Accessibility notes

- Keyboard: activates on <kbd>Enter</kbd> and <kbd>Space</kbd>; the focus ring
  appears only for keyboard focus.
- `onPress` is preferred for new code; `onClick` is bridged for API
  compatibility with the current Paragon Button.
- When rendering icon-only buttons, provide an `aria-label`.
